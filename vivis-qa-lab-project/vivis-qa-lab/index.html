Objective

Assess core vehicle and racing systems through hands-on exploratory testing, focusing on race entry flow, track-load behaviour, HUD accuracy, and monetization UI timing during active gameplay.

Session & Results

Exploratory session covering the core loop: vehicle spawn → mode selection → matchmaking → race → results → store → garage → hub return. During one Talladega race load-in, the speedometer displayed an impossible value (117,575 km/h) while the track surface was still streaming in, followed by the vehicle appearing airborne. This looks like a race condition between asset streaming and vehicle physics initialization — logged below as an active investigation, not a confirmed defect, since it was only captured once.

✅ CONFIRMED ISSUES

No confirmed defects at this stage. The item below requires additional reproduction attempts before being classified as a confirmed bug.

🔍 POTENTIAL ISSUES / OBSERVATIONS
  • Speedometer anomaly during track load-in: While the Talladega circuit banner was displaying and the track geometry had not yet fully streamed in (vehicle resting on a placeholder water plane), the speedometer read 117,575 km/h. The vehicle appeared airborne/flipped shortly after. Suspected cause: physics initializing before track collision mesh finishes loading. Needs reproduction across multiple races/tracks before being logged as confirmed.
  • VIP Game Pass popup timing: The VIP upsell popup appeared while a race-start countdown was actively running behind it. Not confirmed to block input, but worth verifying the popup doesn't cause a missed race start.
